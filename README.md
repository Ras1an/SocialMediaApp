# Wesal API

Wesal (*connection* in Arabic) is a RESTful Web API built with ASP.NET Core 8 for a social media application.  
It provides secure authentication, user profiles, posts, social interactions, and friendship management.

## 🚀 Features
- **Authentication & Authorization**: JWT-based auth with ASP.NET Identity and role-based access.  
- **User Profiles**: Profile creation, updates, and photo management.  
- **Posts & Interactions**: Create, edit, delete posts with image support; like and comment on posts.  
- **Friendship System**: Send, accept, and manage friend requests with friend suggestions.  
- **Timeline Feed**: Personalized feed with friends’ posts.  
- **Search**: Search for users and posts.  

## 🛠️ Technical Highlights
- **Architecture**: Clean Architecture with BLL and DAL layers.  
- **Data Access**: EF Core with SQL Server, Repository Pattern.  
- **Mapping**: AutoMapper integration.  
- **Documentation**: Swagger/OpenAPI.  
- **Frontend**: JavaScript with a web template.  
- **Other**: Pagination, image upload support, CORS enabled.  

## 📚 Technology Stack
- **Backend**: ASP.NET Core 8, C#, EF Core, ASP.NET Identity, JWT  
- **Database**: SQL Server  
- **Frontend**: HTML, CSS, JavaScript  **[Frontend Repo](https://github.com/Ras1an/Wesal-UI)**
- **Tools**: AutoMapper, Swagger, Newtonsoft.Json
